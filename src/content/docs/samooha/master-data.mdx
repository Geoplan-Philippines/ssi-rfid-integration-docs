Samooha POSTs VPM records to Geoplan in a batch. Each record has `operation`: `ADD`, `EDIT`, or `DELETE`.

![Master data sync architecture showing Samooha product data and a direct Geoplan pull from Nedap Harmony](../../../assets/samooha/master-data-sync-revised.png)

Inventory balances and inventory rules stay in Samooha.

## POST deltas

```http
POST https://api-stg-sling.rgoc.com.ph/api/v1/vpm-deltas
x-api-key: <api-key>
Content-Type: application/json
```

Request body:

```json
[
  {
    "operation": "EDIT",
    "vendorName": "ON",
    "vpmCode": "ON-VPM-001",
    "skuCode": "RP80282244",
    "skuName": "Example ON article",
    "barcode": "0123456789012",
    "vpmProductCode": "VPC-001",
    "vpmProductName": "Example VPM product"
  },
  {
    "operation": "DELETE",
    "vpmCode": "ON-VPM-002",
    "skuCode": "RP80282244"
  }
]
```

`barcode` is required for `ADD` and `EDIT`.

Response:

| Rows | HTTP | `message` |
| --- | --- | --- |
| All rows OK | `200` | `Success` |
| Some rows failed | `207` | `Partial success` |
| All rows failed | `422` | `All records failed` |

Failed rows are skipped while the good rows are still saved, so read each row's `status`.

HTTP 207:

```json
{
  "statusCode": 207,
  "message": "Partial success",
  "data": {
    "accepted": 1,
    "rejected": 1,
    "results": [
      {
        "operation": "edit",
        "vpmCode": "ON-VPM-001",
        "skuCode": "RP80282244",
        "status": "success"
      },
      {
        "operation": "add",
        "vpmCode": "ON-VPM-003",
        "skuCode": "RP80282245",
        "status": "failed",
        "error": "barcode should not be empty"
      }
    ]
  }
}
```
